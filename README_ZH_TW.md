# 靈犀 (Lingxi)

**靈犀** —— 一款開源的全能 AI 客戶端應用，讓 AI 真正「心有靈犀」地融入你的手機。

## 核心功能

- **AI 對話**：多模型提供商（OpenAI / Claude / Gemini / DeepSeek / 智譜...）、多助手管理
- **40+ AI 工具**：鬧鐘、日曆、簡訊、相機、手電筒、音量、截圖、螢幕自動化、工作區檔案、SSH...
- **主動訊息 / 自動化**：AI 定時主動發訊息、Tasker 風格工作流
- **微信 Bot**：把微信號變成 AI 入口
- **工作區（內建 Linux）**：自動安裝 Ubuntu rootfs + 程式工具 + APK 反編譯工具（apktool / jadx）
- **搜尋（免 Key）**：Bing / DuckDuckGo / Google / 搜狗 / 360，全部免 API Key
- **語音**：13 家 TTS、5 家 ASR
- **安全**：應用鎖、工具確認、審計日誌
- **外掛系統**：QuickJS 沙箱外掛
- **工具箱**：APK 逆向分析、API 探索器...

## 安裝

下載最新 APK（需 Android 8.0+ / arm64）。
