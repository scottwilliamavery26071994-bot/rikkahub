# Lingxi (灵犀)

**Lingxi** — An open-source all-in-one AI client for Android. Let AI truly understand you.

## Features

- **AI Chat**: Multi-provider (OpenAI / Claude / Gemini / DeepSeek / Zhipu...), multi-assistant management
- **40+ AI Tools**: Alarm, calendar, SMS, camera, torch, volume, screenshot, screen automation, workspace files, SSH, ZIP...
- **Proactive Messaging & Workflow**: AI sends messages on schedule, Tasker-style automation
- **WeChat Bot**: Turn your WeChat into an AI entry
- **Workspace (built-in Linux)**: Auto-installed Ubuntu rootfs + programming tools + APK reverse-engineering tools (apktool / jadx)
- **Search (No Key)**: Bing / DuckDuckGo / Google / Sogou / 360 — all free, no API key needed
- **Voice**: 13 TTS providers, 5 ASR providers
- **Security**: App lock, tool call confirmation, audit log, command guard
- **Plugin System**: QuickJS sandboxed plugins
- **Toolbox**: APK reverse analysis, API explorer, Gomoku...

## Install

Download the latest APK (requires Android 8.0+ / arm64).
