# 灵犀 (Lingxi)

**灵犀** —— 一款开源的全能 AI 客户端应用，让 AI 真正"心有灵犀"地融入你的手机。

## ✨ 核心功能

### 🤖 AI 对话
- 多模型提供商：OpenAI / Claude / Google Gemini / DeepSeek / 通义千问 / 智谱 等
- 多助手管理：每个助手独立配置系统提示词、记忆、MCP、工具开关
- 会话管理：文件夹归类、收藏、历史、消息搜索、自动标题

### 🛠️ AI 工具（40+）
闹钟、日历、短信、通知、相机、手电筒、振动、音量、亮度、壁纸、音乐、截图、屏幕自动化、定位、工作区文件、SSH/SFTP、ZIP 等，AI 可直接调用

### ⚡ 主动消息 / 自动化
- AI 定时主动发消息（带记忆和上下文）
- 设备事件触发（屏幕开关、应用切换）
- Tasker 风格工作流：触发器 + 条件 → 执行动作

### 💬 微信 Bot
扫码登录后，把微信号变成 AI 入口，自动收发消息

### 🌐 工作区（内置 Linux 环境）
- 内置 Ubuntu rootfs 自动安装，免配置
- 自动安装编程工具（git / python3 / gcc / node 等）与 APK 反编译工具（apktool / jadx / dex2jar）
- AI 可在工作区读、写、改、编译、运行代码

### 🔍 搜索（免 Key）
内置 Bing / DuckDuckGo / Google / 搜狗 / 360 搜索引擎，全部免 API Key 直接可用

### 🗣️ 语音
- TTS 朗读（系统 / 百度 / Edge / ElevenLabs / OpenAI 等 13 家）
- ASR 语音识别（系统 / OpenAI Realtime / 火山引擎 等 5 家）

### 🔐 安全
应用锁、工具调用确认、安全审计日志、危险命令守卫

### 📦 插件系统
QuickJS 沙箱插件，支持 WebView 桥接、声明式 UI、权限控制

### 🔧 工具箱
APK 逆向分析、API 探索器、五子棋、火车查询、Base64/JSON/正则 等

## 📥 安装

下载最新 APK 并安装（需 Android 8.0+ / arm64）。
